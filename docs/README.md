# library-android — docs

Documentation for the Android app (Kotlin + Jetpack Compose + Room). Consumes the backend
over REST and the `recommender` logic on-device via a UniFFI binding (artifact from
`library-backend/build.sh`).

```
docs/
├── sow/   Statement of Work
├── prd/   Product Requirements
├── fsd/   Functional Spec
├── plan/  Implementation Plan + environment setup
└── adr/   Architecture Decision Records
```
Start here if new to Android: `plan/002-environment-setup-android.md`.
